for loop
Repeats code a set number of times. It has three parts: a start (let i = 0), a condition to keep going (i < menu.length), and a step (i++). Use menu[i] to get the current item. 
for (let i = 0; i < menu.length; i++) {
  console.log(menu[i].name);
}
forEach
A shorter way to loop over an array. It hands your function each item, one at a time, so you don't need i. 
menu.forEach(function (item) {
  console.log(item.name);
});
Adding up with a loop
Start a variable at 0 before the loop, then add to it on each pass: total = total + item.price;
