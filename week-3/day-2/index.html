Methods
A function stored inside an object. You call it with a dot: truck.describe().
this
Inside a method, this means "the object I belong to," so this.name reads the truck's own name. Watch out: arrow functions (() => {}) don't get their own this, so use a regular function for methods. 
const truck = {
  name: "Taco Rocket",
  describe: function () {
    return "Welcome to " + this.name + "!";
  },
};
JSON
Text that looks like an object. Apps use it to save and send data. JSON.parse(text) turns JSON text into a real object. JSON.stringify(object) turns an object back into text. 
const text = '{"name": "taco", "price": 4.5}';
const item = JSON.parse(text);   // object
JSON.stringify(item);            // string again
