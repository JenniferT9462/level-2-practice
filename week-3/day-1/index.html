Variables
A named box that holds a value. Use const when the value won't change and let when it will. Values have types: a string (text), a number, or a boolean (true/false). typeof tells you which one you have. 
const truckName = "Taco Rocket";
let yearsOpen = 3;
Arrays
An ordered list inside square brackets. Counting starts at 0, so the first item is [0]. .length tells you how many items there are. 
const menu = ["taco", "burrito", "nachos"];
menu[0];      // "taco"
menu.length;  // 3
Objects
One thing with named details, called properties, inside curly braces. Read a property with dot notation (item.name) or bracket notation (item["name"]). 
const item = { name: "taco", price: 4.5, spicy: true };
Functions
A reusable recipe. You give it inputs (parameters), and it returns an answer. Nothing happens until you call it. 
function addTip(price, tip) {
  return price + tip;
}
addTip(10, 2);  // 12
