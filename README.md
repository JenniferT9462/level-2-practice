# Level 2 Practice

Your practice space for the **non-graded** days of Level 2. Fork it once and
use it all course. Each week, a new folder shows up here.

> Graded work (assignments and projects) goes in **new repos**, not this one.

## Get your copy (once, Week 3 Day 1)

1. On GitHub, click **Fork** (top right) → **Create fork**.
2. On *your* fork, click the green **Code** button → copy the link.
3. In VS Code: `Ctrl+Shift+P` → **Git: Clone** → paste the link → pick a folder → **Open**.

## Get each new week (every Monday)

1. On *your* fork on GitHub, click **Sync fork** → **Update branch**.
2. In VS Code, click **Sync** (the circling arrows at the bottom left).
3. The new week's folder appears.

> **Only edit files inside the `week-N/` folders.** If you change this README
> or the home page, Sync fork may stop working.

## Each practice day

1. Open that day's `script.js`. Read the **Example**, then do each **TODO** below it.
2. Right-click that day's `index.html` → **Open with Live Server**.
3. Open the console: right-click the page → **Inspect** → **Console** tab.
4. Save often. The page reloads by itself.

## Save your work (the 3 save-point commands)

```bash
git add .
git commit -m "Week 3 Day 1: variables and objects"
git push
```

## Stuck?

- **Red error in the console?** Read the line number on the right. Go to that line.
- **Nothing shows up?** Check you saved the file, and that you are looking at the right day's page.
- Still stuck after 10 minutes? Ask in the breakout room or in chat.
